# qq-ui

Holding place until this plugin has a wiki.

Independent regions. Same rule as Cordis fibers: a piece that did not change is not torn down, and does not hitch its neighbors.

This console is HTMX. One `sse-connect`, named events, named `sse-swap` targets. Status is not the transcript. Settled messages are not the streaming tail. The composer is not the heading. Popups are not the chrome. The drawer and project rail live outside the session stream. The composer owns a local chair-mode toggle (`nav` / session); navigation mode is a client island and must not hitch HTMX regions.

The transcript cell is the current DSH surface, not the raw log: `surfaceOp: replace` drops shadowed nodes and leaves the stub. A closed tool card is a summary; its body loads on open. First paint must not inline closed bodies.

Do not replace `#session-panel` as one blob because something in the session changed. POSTs update named regions with `hx-swap="none"` and out-of-band `innerHTML`. Prompt/interrupt do not OOB the queue; SSE owns pending. The live suffix is one `#transcript-live-nodes` mixed in log order. New nodes `qq-live-insert` as siblings. Token suffixes use `live-append` / `qq-live-append` on the same EventSource and patch the existing `.message-live-text` by node id; they must not go through HTMX `sse-swap`. Visible text is held briefly then leaked at a steady rate (jitter buffer); tools, junctions, and seal flush. Tool progress and seal `qq-live-replace` that node in place. Markdown promotion happens when the assistant node settles, not when a tool appears. Completing a tool must not reparent it over still-live content. Settled is a prefix of the same list; nodes append into `#transcript-settled` unless a replace recommissions it. There are no `#transcript-live-text` / `#transcript-live-tool` islands. Follow stays snapped to the live tail unless the operator scrolls up; send blurs the composer and re-anchors. A provider-gap caret occupies a reserved slot at the end of `#transcript-live` (padding, not a newly inserted row) while the turn is running, no tool is live, and tokens have been silent ≥1s; send arms it before interrupt lands; revealing it must not shift the transcript; elapsed seconds start with the caret; tools, tokens, and seal idle the slot without collapsing it. The composer sits on equal inset from the transcript cutoff and the screen edge (plus safe-area). Queued/steering inbox rows sit in `#transcript-live` above the provider-gap caret as muted assistant-like lines with a queued mark, not user bubbles or a labeled dock. Interrupt idles the caret immediately. Reasoning is shown whenever its node has reasoning text and remains visible in both the live suffix and settled transcript, independent of busy or turn state.

Stay on this stack. Do not add a second UI framework. Morphing a god-node is not independence. Client islands stay a closed list: composer draft, transcript follow, live text patch, provider-gap caret, drawer drag, chair mode, dictation, ui generation reload.

Live CSS/JS are `/assets/console.css` and `/assets/browser.js`. The service worker must not cache them. An SSE `ui` event carries the generation the process is serving; mismatch reloads the page once. Do not bump versioned asset names for live chrome.
